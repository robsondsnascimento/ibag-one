# ⛪ Domínio: Culto

## Contexto

O culto representa uma das principais programações da IBAG.

Cada Campus possui suas próprias celebrações.

---

# Estrutura

```
IBAG

|

Campus

|

Culto
```

---

# Exemplo

```
IBAG Cachoeirinha

Celebração Domingo

02/08/2026

19:30
```

---

# Ordem de Culto

A Ordem de Culto representa a sequência operacional da celebração.

Não deve ser apenas texto.

Ela possui etapas.

---

# Estrutura

```
Culto

|

Ordem

|

Itens
```

---

# Item da Ordem

Cada item pode possuir:

- horário;
- responsável;
- área envolvida;
- materiais;
- observações.

---

# Exemplo

```
Culto Domingo

19:30

Abertura

Responsável:
Equipe Culto


Louvor

Responsável:
Música

Músicas:

- Vem com Josué lutar em Jericó

- Toque em mim de novo


Avisos

Responsável:
Comunicação


Mensagem

Responsável:
Pastor
```

---

# Materiais

Um item pode exigir:

- card;
- vídeo;
- apresentação;
- música;
- ProPresenter.

---

# Demandas por Área

A ordem gera tarefas.

Exemplo:

```
Louvor

Enviar repertório até terça


Comunicação

Enviar cards até quinta


Mídia

Preparar vídeos
```

Ao incluir um item e informar a área responsável, a Ordem de Culto cria uma demanda pendente e encaminha o aviso à liderança compatível com o campus. A remoção do item encerra suas demandas e materiais e avisa a mesma liderança para que os preparativos sejam interrompidos.

O modelo do Culto Cachoeirinha organiza o repertório em cinco momentos: celebração de início, celebração ou POP, oração, dízimos e ofertas e celebração final. Cada música aprovada pode carregar o link de sua versão no YouTube e é distribuída automaticamente para o momento correspondente.

---

# Responsável pela Ordem

Cada Campus possui uma pessoa responsável pela montagem da ordem.

Ela organiza:

- sequência;
- informações;
- demandas.
