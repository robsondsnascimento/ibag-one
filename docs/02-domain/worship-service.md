# ⛪ Domínio: Culto

## Contexto

O culto representa uma das principais programações da IBAG.

Cada Campus possui suas próprias celebrações.

---

# Estrutura

```
IBAG

|

Campus

|

Culto
```

---

# Exemplo

```
IBAG Cachoeirinha

Celebração Domingo

02/08/2026

19:30
```

---

# Ordem de Culto

A Ordem de Culto representa a sequência operacional da celebração.

Não deve ser apenas texto.

Ela possui etapas.

---

# Estrutura

```
Culto

|

Ordem

|

Itens
```

---

# Item da Ordem

Cada item pode possuir:

- horário;
- responsável;
- área envolvida;
- materiais;
- observações.

---

# Exemplo

```
Culto Domingo

19:30

Abertura

Responsável:
Equipe Culto


Louvor

Responsável:
Música

Músicas:

- Vem com Josué lutar em Jericó

- Toque em mim de novo


Avisos

Responsável:
Comunicação


Mensagem

Responsável:
Pastor
```

---

# Materiais

Um item pode exigir:

- card;
- vídeo;
- apresentação;
- música;
- ProPresenter.

---

# Demandas por Área

A ordem gera tarefas.

Exemplo:

```
Louvor

Enviar repertório até terça


Comunicação

Enviar cards até quinta


Mídia

Preparar vídeos
```

---

# Responsável pela Ordem

Cada Campus possui uma pessoa responsável pela montagem da ordem.

Ela organiza:

- sequência;
- informações;
- demandas.
