# 👤 Entidade: Pessoa

## Contexto

Pessoa é a entidade central do IBAG One.

Todo relacionamento da plataforma nasce a partir de uma pessoa.

Uma pessoa pode ser:

- membro;
- criança;
- líder;
- integrante de serviço;
- pastor;
- participante de célula.

O sistema não cria entidades separadas para cada função.

---

# Princípio

```
Uma pessoa

↓

Uma história

↓

Muitos relacionamentos
```

---

# Dados pessoais

Campos principais:

```
Nome completo

Data de nascimento

Sexo

CPF

Foto principal

Estado civil

Contato

Endereço
```

---

# Contatos

Uma pessoa pode possuir:

```
Telefone

Email

WhatsApp

Outros contatos
```

---

# Endereço

O endereço possui histórico.

Exemplo:

```
2026

Cachoeirinha


2030

Esteio
```

---

# Família

Uma pessoa pode pertencer a uma família.

Exemplo:

```
Família Oliveira

João

Maria

Lucas
```

Relacionamentos:

- pai;
- mãe;
- filho;
- cônjuge;
- responsável.

---

# Campus

Uma pessoa possui:

```
Campus atual

+

Histórico de Campus
```

Mudanças não removem histórico.

---

# Estado civil

O sistema mantém histórico.

Exemplo:

```
Solteiro

↓

Casado
```

---

# Conversão

A decisão por Jesus é registrada.

Informações:

```
Data

Campus

Responsável pela consolidação
```

---

# Batismo

Informações:

```
Data

Campus

Ministro responsável

Certificado
```

---

# Alertas de cuidado

O sistema pode gerar lembretes:

```
1 ano de conversão

2 anos de conversão

5 anos de conversão

Aniversário de batismo
```

Objetivo:

Ajudar no acompanhamento pastoral.

---

# Célula

Uma pessoa pode participar de células.

Histórico mantido.

---

# Áreas de Serviço

Uma pessoa pode servir em várias áreas.

Exemplo:

```
Louvor

Comunicação

Ensino
```

---

# Liderança

A história de liderança é preservada.

Exemplo:

```
2026

Líder de Célula


2028

Supervisor
```

---

# Dados sensíveis

Informações restritas:

```
Acompanhamentos pastorais

Aconselhamentos

Situações familiares

Necessidades especiais
```

Controle através de permissões.

---

# Fotos

O sistema suporta múltiplos tipos:

```
Foto de perfil

Fotos de família

Fotos de eventos

Registros históricos
```

---

# Status

Pessoa nunca é apagada.

Estados possíveis:

```
ATIVO

INATIVO

TRANSFERIDO

DESLIGADO
```

---

# Objetivo

Permitir que a IBAG One responda:

"Quem é essa pessoa?"

"Quem cuida dela?"

"Qual sua caminhada?"

"Como podemos servir melhor?"
