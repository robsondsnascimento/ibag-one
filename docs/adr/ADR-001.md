# ADR-001

## Título

As Células são o domínio central do IBAG One.

## Status

Aceito

## Contexto

A IBAG é uma igreja baseada no modelo celular.

O discipulado acontece principalmente através das células.

## Decisão

O módulo de células será o principal domínio do sistema.

Todos os demais módulos serão integrados a ele.

## Consequências

Toda arquitetura deverá respeitar esta decisão.
