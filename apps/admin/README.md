# IBAG One Admin

Painel administrativo web do IBAG One, construído com React, TypeScript e Vite.

## Executar localmente

```powershell
npm install
npm run dev
```

Abra `http://127.0.0.1:5173` no navegador.

## Verificações

```powershell
npm run build
npm run lint
```

## Estrutura

- `src/App.tsx`: conteúdo e interações das telas.
- `src/App.css`: layout, componentes e temas claro/noturno.
- `src/index.css`: estilos globais.
- `.env.example`: endereço da API quando a integração for ativada.
