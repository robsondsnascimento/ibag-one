# IBAG One

> Plataforma oficial da IBAG

**Codinome:** Project Nehemiah

---

## 📖 Sobre o Projeto

O IBAG One é uma plataforma desenvolvida para apoiar a gestão completa da IBAG, integrando pessoas, Campus, ministérios, equipes, eventos, escalas, comunicação e processos administrativos em um único ecossistema.

Mais do que um sistema, o IBAG One pretende preservar a história da organização, facilitar o cuidado com as pessoas e fortalecer a missão da Igreja através da tecnologia.

---

## 🎯 Missão

Fortalecer a missão da IBAG através de uma plataforma moderna, segura, escalável e centrada nas pessoas.

---

## 👁️ Visão

Ser a plataforma oficial da IBAG, conectando todos os Campi e ministérios em um único ambiente digital.

---

## 🏛 Project Nehemiah

Project Nehemiah é o codinome de engenharia utilizado durante a arquitetura e desenvolvimento da plataforma.

Inspirado em Neemias, representa planejamento, organização e construção com propósito.

---

## 🏗 Arquitetura

A plataforma será construída utilizando:

- Flutter
- Flutter Web
- NestJS
- PostgreSQL
- Redis
- Docker
- RabbitMQ
- API First
- Domain Driven Design (DDD)
- Clean Architecture
